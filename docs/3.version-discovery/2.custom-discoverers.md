Puedes crear tu propio descubridor de versiones extendiendo la clase abstracta `VersionDiscoverer` e implementando el método `rules()`.

## Implementación de `rules()`

`rules()` debe devolver un objeto `Record<string, string>` donde:
- La **clave** es el número de versión esperado (por ejemplo `'2.0'`).
- El **valor** es el nombre del atributo donde se encuentra esa versión (por ejemplo `'Version'` o `'version'`).

El método `discover()` evalúa las reglas en el orden en que aparecen en el objeto y retorna la primera coincidencia exacta, o `''` si ninguna coincide.

```ts [pagos-version.ts]
import { VersionDiscoverer, XmlNode } from '@nodecfdi/cfdi-core';

export class PagosVersion extends VersionDiscoverer {
  public rules(): Record<string, string> {
    return {
      '2.0': 'Version',
      '1.0': 'Version',
    };
  }
}

const pagosNode = new XmlNode('pago20:Pagos', { Version: '2.0' });
const version = new PagosVersion().getFromNode(pagosNode);
console.log(version); // '2.0'
```

## Contenedores personalizados

Si deseas consultar atributos desde otra estructura (por ejemplo un objeto plano o una clase propia) sin convertirla a `XmlNode` o `Element`, implementa `ContainerWithAttributeInterface`:

```ts [custom-container.ts]
import type { ContainerWithAttributeInterface } from '@nodecfdi/cfdi-core/types';
import { CfdiVersion } from '@nodecfdi/cfdi-core';

class RecordContainer implements ContainerWithAttributeInterface {
  public constructor(private readonly data: Record<string, string>) {}

  public getAttributeValue(attribute: string): string {
    return this.data[attribute] ?? '';
  }
}

const version = new CfdiVersion().discover(
  new RecordContainer({ Version: '4.0' }),
);
console.log(version); // '4.0'
```

Para los casos estándar ya se incluyen `NodeContainer` (envuelve `XmlNodeInterface`) y `DomElementContainer` (envuelve `Element`).
