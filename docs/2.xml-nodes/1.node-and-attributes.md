`XmlNode` representa un elemento XML con un nombre válido, una colección de atributos (`XmlAttributes`), una colección de nodos hijos (`XmlNodes`), texto (`value`) y contenido `CDATA`.

## Creación de un nodo

El constructor de `XmlNode` valida que el nombre sea un identificador XML válido mediante `isValidXmlName` (si no lo es, lanza un `SyntaxError`).

```ts [crear-nodo.ts]
import { XmlNode } from '@nodecfdi/cfdi-core';

const concepto = new XmlNode('cfdi:Concepto', {
  ClaveProdServ: '01010101',
  Cantidad: '1',
  Unidad: 'Pieza',
  Descripcion: 'Producto de prueba',
  ValorUnitario: '100.00',
  Importe: '100.00',
});
```

### Tipado genérico de atributos

Puedes pasar un tipo unión en el parámetro genérico `TAttributes` para obtener autocompletado en los métodos de atributos, sin perder la flexibilidad de usar cualquier otro atributo XML:

```ts [nodo-tipado.ts]
import { XmlNode } from '@nodecfdi/cfdi-core';

type ComprobanteAttrs = 'Version' | 'Serie' | 'Folio' | 'Total';

const comprobante = new XmlNode<ComprobanteAttrs>('cfdi:Comprobante', {
  Version: '4.0',
  Total: '116.00',
});

const version = comprobante.getAttribute('Version'); // '4.0'
```

## Manipulación de atributos

`XmlNode` delega el manejo de atributos a `XmlAttributes`, accesible directamente con `node.attributes()`.

- `getAttribute(name)`: Devuelve el valor como `string` o cadena vacía `''` si no existe.
- `setAttribute(name, value)`: Establece el valor; si se pasa `null`, elimina el atributo.
- `hasAttribute(name)`: Indica si el atributo existe.
- `addAttributes(record)`: Importa múltiples atributos desde un objeto; los valores `null` o `undefined` eliminan la clave, y números, booleanos u objetos con `toString()` se convierten automáticamente a `string`.

```ts [atributos.ts]
import { XmlNode } from '@nodecfdi/cfdi-core';

const emisor = new XmlNode('cfdi:Emisor');
emisor.addAttributes({
  Rfc: 'EKU9003173C9',
  Nombre: 'ESCUELA KEMPER URGATE',
  RegimenFiscal: 601,
});

// Eliminar un atributo pasando null
emisor.setAttribute('Nombre', null);

// Iterar sobre los atributos
for (const [clave, valor] of emisor.attributes()) {
  console.log(`${clave}=${valor}`);
}
```

## Texto y secciones CDATA

Un nodo puede almacenar texto plano y contenido CDATA por separado:

```ts [texto-cdata.ts]
import { XmlNode } from '@nodecfdi/cfdi-core';

const nodoTexto = new XmlNode('cfdi:Texto', {}, [], 'Contenido de texto');
nodoTexto.setValue('Texto actualizado');

const addenda = new XmlNode('cfdi:Addenda');
addenda.setCData('<DatosPersonalizados id="1"/>');
```

## Búsqueda por ruta en el árbol

`XmlNode` permite navegar hacia descendientes usando rutas de nombres de nodos como argumentos variables:

- `searchNode(...searchPath)`: Devuelve el primer nodo que coincide con la ruta o `undefined`.
- `searchNodes(...searchPath)`: Devuelve un `XmlNodes` con todos los hijos cuyo nombre coincide con el último segmento de la ruta.
- `searchAttribute(...searchPath)`: Busca el nodo indicado y devuelve el valor del atributo especificado en el último argumento (o `''` si no existe).

```ts [busqueda.ts]
import { XmlNode } from '@nodecfdi/cfdi-core';

const root = new XmlNode('cfdi:Comprobante', { Version: '4.0' });
const conceptos = root.addChild(new XmlNode('cfdi:Conceptos'));
conceptos.addChild(new XmlNode('cfdi:Concepto', { ClaveProdServ: '01010101' }));
conceptos.addChild(new XmlNode('cfdi:Concepto', { ClaveProdServ: '84111506' }));

const emisor = root.addChild(
  new XmlNode('cfdi:Emisor', { Rfc: 'EKU9003173C9' }),
);

// Buscar un atributo en un nodo hijo
const rfc = root.searchAttribute('cfdi:Emisor', 'Rfc'); // 'EKU9003173C9'

// Obtener todos los nodos cfdi:Concepto dentro de cfdi:Conceptos
const listaConceptos = root.searchNodes('cfdi:Conceptos', 'cfdi:Concepto');
console.log(listaConceptos.length); // 2

// Verificar si existe un nodo
const nodoEmisor = root.searchNode('cfdi:Emisor');
console.log(nodoEmisor === emisor); // true
```
