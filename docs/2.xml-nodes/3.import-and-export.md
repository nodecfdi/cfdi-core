`@nodecfdi/cfdi-core` ofrece funciones de conveniencia y clases dedicadas para convertir entre árboles `XmlNodeInterface`, cadenas XML y elementos DOM (`Element` de `@xmldom/xmldom`).

## Funciones de conversión rápida

Las funciones exportadas cubren los flujos más comunes:

- `nodeFromXmlString(content)`: Parsea una cadena XML y devuelve el nodo raíz como `XmlNodeInterface`.
- `nodeFromXmlElement(element)`: Convierte un `Element` existente en `XmlNodeInterface`.
- `nodeToXmlString(node, withXmlHeader = false)`: Serializa un `XmlNodeInterface` a cadena XML. Si `withXmlHeader` es `true`, antepone `<?xml version="1.0" encoding="UTF-8"?>`.
- `nodeToXmlElement(node)`: Convierte un `XmlNodeInterface` en un `Element` del DOM.

```ts [conversion.ts]
import {
  nodeFromXmlString,
  nodeToXmlElement,
  nodeToXmlString,
  XmlNode,
} from '@nodecfdi/cfdi-core';

const xmlInput = `
<cfdi:Comprobante xmlns:cfdi="http://www.sat.gob.mx/cfd/4" Version="4.0">
  <cfdi:Emisor Rfc="EKU9003173C9"/>
</cfdi:Comprobante>
`;

// Importar desde string XML
const root = nodeFromXmlString(xmlInput);
console.log(root.getAttribute('Version')); // '4.0'
console.log(root.searchAttribute('cfdi:Emisor', 'Rfc')); // 'EKU9003173C9'

// Exportar a string XML con declaración <?xml ...?>
const xmlOutput = nodeToXmlString(root, true);

// Exportar a Element DOM
const domElement = nodeToXmlElement(root);
console.log(domElement.tagName); // 'cfdi:Comprobante'
```

## Uso de `XmlNodeImporter` y `XmlNodeExporter`

Internamente, las funciones anteriores utilizan `XmlNodeImporter` y `XmlNodeExporter`. Puedes instanciarlas directamente si trabajas con elementos DOM ya construidos:

```ts [importer-exporter.ts]
import {
  documentElement,
  newDocumentContent,
  XmlNodeExporter,
  XmlNodeImporter,
} from '@nodecfdi/cfdi-core';

const doc = newDocumentContent('<root id="1"><item>Hola</item></root>');
const element = documentElement(doc);

// Importar desde Element
const node = new XmlNodeImporter(element).import();
console.log(node.searchNode('item')?.value()); // 'Hola'

// Exportar hacia Element
const exportedElement = new XmlNodeExporter(node).export();
console.log(exportedElement.getAttribute('id')); // '1'
```

::note
Al importar un elemento con prefijo de espacio de nombres (como `cfdi:Comprobante`), `XmlNodeImporter` registra automáticamente `xmlns:<prefijo>` y `xmlns:xsi` en el primer nodo donde aparecen para evitar duplicar definiciones en cada nodo hijo.
::
