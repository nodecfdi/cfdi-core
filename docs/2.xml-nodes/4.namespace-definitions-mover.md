En los comprobantes CFDI y sus complementos (como Timbre Fiscal Digital, Pagos o Nómina), es común que al ensamblar nodos de distintas fuentes queden declaraciones `xmlns:*` o atributos `xsi:schemaLocation` dispersos en nodos hijos. El estándar del SAT exige consolidar estas definiciones en el nodo raíz (`cfdi:Comprobante`).

## `SatNsDefinitionsMover`

`SatNsDefinitionsMover` recorre el árbol de nodos y mueve al nodo raíz todas las definiciones `xmlns:*` y `xsi:schemaLocation` cuyo espacio de nombres comience con `http://www.sat.gob.mx/`, eliminándolas de los nodos hijos:

```ts [mover-sat.ts]
import {
  nodeFromXmlString,
  nodeToXmlString,
  SatNsDefinitionsMover,
} from '@nodecfdi/cfdi-core';

const xml = `
<cfdi:Comprobante xmlns:cfdi="http://www.sat.gob.mx/cfd/4"
  xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
  xsi:schemaLocation="http://www.sat.gob.mx/cfd/4 http://www.sat.gob.mx/sitio_internet/cfd/4/cfdv40.xsd">
  <cfdi:Complemento>
    <tfd:TimbreFiscalDigital
      xmlns:tfd="http://www.sat.gob.mx/TimbreFiscalDigital"
      xsi:schemaLocation="http://www.sat.gob.mx/TimbreFiscalDigital http://www.sat.gob.mx/sitio_internet/cfd/TimbreFiscalDigital/TimbreFiscalDigitalv11.xsd"
      Version="1.1"/>
  </cfdi:Complemento>
</cfdi:Comprobante>
`;

const root = nodeFromXmlString(xml);
new SatNsDefinitionsMover().move(root);

console.log(root.getAttribute('xmlns:tfd'));
// 'http://www.sat.gob.mx/TimbreFiscalDigital'
console.log(nodeToXmlString(root));
```

## `NodeNsDefinitionsMover` con filtro personalizado

Si necesitas mover espacios de nombres de otros dominios (o mover absolutamente todos), utiliza `NodeNsDefinitionsMover`:

- Sin filtro (`setNamespaceFilter(null)` o por defecto): mueve **todas** las definiciones `xmlns:<prefijo>` y `xsi:schemaLocation` encontradas en los hijos.
- Con filtro (`setNamespaceFilter((ns) => ...)`): solo mueve los espacios de nombres para los cuales la función devuelva `true`.

```ts [mover-personalizado.ts]
import { nodeFromXmlString, NodeNsDefinitionsMover } from '@nodecfdi/cfdi-core';

const root = nodeFromXmlString(`
<root xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance">
  <custom:Item xmlns:custom="https://ejemplo.com/ns"
    xsi:schemaLocation="https://ejemplo.com/ns https://ejemplo.com/ns.xsd"/>
</root>
`);

const mover = new NodeNsDefinitionsMover();
mover.setNamespaceFilter((namespace) =>
  namespace.startsWith('https://ejemplo.com/'),
);
mover.process(root);

console.log(root.getAttribute('xmlns:custom')); // 'https://ejemplo.com/ns'
```
