La clase `XmlNodes` extiende `Array<XmlNodeInterface>`, por lo que es iterable y compatible con métodos de arreglo estándar, añadiendo deduplicación por referencia de objeto y ordenamiento automático por nombre de nodo.

## Operaciones básicas en `XmlNodes`

Puedes acceder a la colección de hijos de un `XmlNode` mediante `node.children()` o instanciar `new XmlNodes()` directamente:

```ts [coleccion.ts]
import { XmlNode } from '@nodecfdi/cfdi-core';

const conceptos = new XmlNode('cfdi:Conceptos');
const c1 = new XmlNode('cfdi:Concepto', { Descripcion: 'Servicio A' });
const c2 = new XmlNode('cfdi:Concepto', { Descripcion: 'Servicio B' });

conceptos.children().add(c1, c2);

// Agregar el mismo nodo de nuevo no lo duplica
conceptos.children().add(c1);
console.log(conceptos.length); // 2

// Obtener por posición (lanza RangeError si no existe)
const primero = conceptos.children().get(0);

// Buscar por nombre
const primerConcepto = conceptos.children().firstNodeWithName('cfdi:Concepto');
const todos = conceptos.children().getNodesByName('cfdi:Concepto');
```

::note
`XmlNodes` utiliza `Symbol.species` apuntando a `Array`, por lo que métodos como `.map()` o `.filter()` devuelven un `Array` nativo en lugar de intentar construir un `XmlNodes`.
::

## Ordenamiento de nodos hijos

Los esquemas XSD del SAT exigen que los nodos hijos de un comprobante aparezcan en una secuencia estricta. Puedes definir ese orden en `XmlNodes` con `setOrder(names)`:

```ts [ordenamiento.ts]
import { XmlNode } from '@nodecfdi/cfdi-core';

const comprobante = new XmlNode('cfdi:Comprobante', { Version: '4.0' });

// Se agregan en cualquier orden
comprobante.addChild(new XmlNode('cfdi:Conceptos'));
comprobante.addChild(new XmlNode('cfdi:Receptor', { Rfc: 'XAXX010101000' }));
comprobante.addChild(new XmlNode('cfdi:Emisor', { Rfc: 'EKU9003173C9' }));

// Se define el orden esperado según el XSD de CFDI 4.0
comprobante.children().setOrder([
  'cfdi:InformacionGlobal',
  'cfdi:CfdiRelacionados',
  'cfdi:Emisor',
  'cfdi:Receptor',
  'cfdi:Conceptos',
  'cfdi:Impuestos',
  'cfdi:Complemento',
  'cfdi:Addenda',
]);

// Los hijos quedan ordenados automáticamente y cualquier nodo nuevo respetará el orden
for (const child of comprobante) {
  console.log(child.name());
}
// Salida:
// cfdi:Emisor
// cfdi:Receptor
// cfdi:Conceptos
```

Los nodos cuyo nombre no aparece en la lista de `setOrder()` se colocan al final, conservando su orden relativo de inserción.

## Uso directo de `XmlNodesSorter`

Si necesitas ordenar un arreglo de `XmlNodeInterface` sin mutar una colección `XmlNodes`, utiliza `XmlNodesSorter`:

```ts [sorter.ts]
import { XmlNode, XmlNodesSorter } from '@nodecfdi/cfdi-core';

const sorter = new XmlNodesSorter(['cfdi:Emisor', 'cfdi:Receptor']);
const nodos = [
  new XmlNode('cfdi:Conceptos'),
  new XmlNode('cfdi:Receptor'),
  new XmlNode('cfdi:Emisor'),
];

const ordenados = sorter.sort(nodos);
console.log(ordenados.map((n) => n.name()));
// ['cfdi:Emisor', 'cfdi:Receptor', 'cfdi:Conceptos']
```
