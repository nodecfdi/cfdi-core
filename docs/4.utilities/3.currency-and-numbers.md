El paquete incluye utilidades basadas en `decimal.js` para evitar errores de precisión de punto flotante al redondear y formatear importes, así como helpers para fechas en formato CFDI.

## `CurrencyDecimals`

`CurrencyDecimals` valida códigos de moneda ISO de 3 letras mayúsculas y un número entero no negativo de decimales:

```ts [monedas.ts]
import { CurrencyDecimals } from '@nodecfdi/cfdi-core';

// Crear desde monedas conocidas: MXN (2), EUR (2), USD (2), XXX (0)
const mxn = CurrencyDecimals.newFromKnownCurrencies('MXN');
console.log(mxn.decimals()); // 2
console.log(mxn.round('123.456').toString()); // '123.46'
console.log(mxn.doesNotExceedDecimals('123.45')); // true
console.log(mxn.doesNotExceedDecimals('123.456')); // false

// Usar un valor por defecto para otras monedas no incluidas en la tabla interna
const jpy = CurrencyDecimals.newFromKnownCurrencies('JPY', 0);
console.log(jpy.decimals()); // 0
```

::note
Si se llama a `CurrencyDecimals.newFromKnownCurrencies(currency)` con una moneda desconocida sin proporcionar `defaultDecimals`, lanzará un `RangeError`.
::

## Funciones de formato y números

- `formatNumber(value, decimals = 2)`: Formatea un valor numérico (`Decimal.Value`) con decimales fijos usando `Decimal#toFixed`.
- `formatDatetime(value, useUtc = false)`: Formatea un `Date` o timestamp numérico al formato `YYYY-MM-DDTHH:mm:ss` requerido por el SAT (en hora local o UTC si `useUtc` es `true`). Lanza `RangeError` si la fecha es inválida.
- `roundNumber(num, precision)`: Redondea con `Decimal` a la precisión indicada y devuelve `number`.
- `toFloat(value)`: Convierte una cadena a `number`, devolviendo `0` si el resultado es `NaN`.

```ts [formatos.ts]
import {
  formatDatetime,
  formatNumber,
  roundNumber,
  toFloat,
} from '@nodecfdi/cfdi-core';

console.log(formatNumber('100.5', 2)); // '100.50'
console.log(roundNumber('10.125', 2)); // 10.13
console.log(toFloat('abc')); // 0

const fecha = new Date('2026-03-15T14:30:00Z');
console.log(formatDatetime(fecha, true)); // '2026-03-15T14:30:00'
```
