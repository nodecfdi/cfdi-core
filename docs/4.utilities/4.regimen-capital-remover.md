En CFDI 4.0, el atributo `Nombre` del emisor y del receptor debe coincidir con la denominación o razón social registrada ante el SAT **sin** el régimen de capital (por ejemplo, `SA DE CV`, `S DE RL DE CV`, `SAPI DE CV`, `SC`, `AC`).

`RegimenCapitalRemover` elimina automáticamente esos sufijos al final de la cadena (sin distinguir entre mayúsculas y minúsculas).

## Uso predeterminado

`RegimenCapitalRemover.createDefault()` incluye más de 150 sufijos societarios del catálogo del IMSS:

```ts [regimen-default.ts]
import { RegimenCapitalRemover } from '@nodecfdi/cfdi-core';

const remover = RegimenCapitalRemover.createDefault();

console.log(remover.remove('ESCUELA KEMPER URGATE SA DE CV'));
// 'ESCUELA KEMPER URGATE'

console.log(remover.remove('EMPRESA EJEMPLO S.A. DE C.V.'));
// 'EMPRESA EJEMPLO S.A. DE C.V.' (los sufijos se comparan sin puntos adicionales)

console.log(remover.remove('COMERCIALIZADORA DEL NORTE S DE RL DE CV'));
// 'COMERCIALIZADORA DEL NORTE'
```

## Sufijos personalizados

Si necesitas una lista específica de sufijos, instancia la clase directamente pasando los sufijos como argumentos. Si todos los sufijos son cadenas vacías o no se pasa ninguno, el constructor lanza un `Error`:

```ts [regimen-custom.ts]
import { RegimenCapitalRemover } from '@nodecfdi/cfdi-core';

const customRemover = new RegimenCapitalRemover('SA DE CV', 'SAPI DE CV');

console.log(customRemover.remove('MI EMPRESA SAPI DE CV')); // 'MI EMPRESA'
console.log(customRemover.remove('MI EMPRESA SC')); // 'MI EMPRESA SC'
```
