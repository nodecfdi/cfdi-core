`@nodecfdi/cfdi-core` encapsula `@xmldom/xmldom` con funciones seguras para crear documentos, parsear cadenas XML con detección estricta de errores y validar tipos de nodos DOM.

## Instancias DOM

- `getParser()`: Crea un `DOMParser` configurado con `onError: onErrorStopParsing` para detener el parseo ante XML inválido.
- `getSerializer()`: Crea un `XMLSerializer`.
- `getDomImplementation()`: Crea un `DOMImplementation`.

## Helpers de documentos y elementos

- `newDocument(document?)`: Devuelve el `Document` recibido o crea uno nuevo vacío.
- `newDocumentContent(content)`: Parsea una cadena XML no vacía y devuelve un `Document` (lanza `TypeError` si está vacía o `Error` si falla el parseo).
- `documentElement(document)`: Devuelve el elemento raíz del documento o lanza `TypeError` si no existe.
- `ownerDocument(node)`: Devuelve el `Document` propietario del nodo (o el mismo nodo si es un `Document`).
- `createElement(document, name, content = '')`: Crea un elemento en el documento dado y opcionalmente agrega un nodo de texto.
- `createDomElement(makeElement, errorMessage, content)`: Helper genérico para crear elementos con manejo uniforme de errores.
- `isValidXmlName(name)`: Valida si una cadena es un nombre XML válido.

```ts [dom-helpers.ts]
import {
  createElement,
  documentElement,
  getSerializer,
  newDocumentContent,
} from '@nodecfdi/cfdi-core';

const doc = newDocumentContent('<cfdi:Comprobante Version="4.0"/>');
const root = documentElement(doc);

const emisor = createElement(doc, 'cfdi:Emisor');
emisor.setAttribute('Rfc', 'EKU9003173C9');
root.appendChild(emisor);

const xml = getSerializer().serializeToString(doc);
console.log(xml);
```

## Type guards para nodos DOM

Para inspeccionar nodos provenientes de `@xmldom/xmldom` de forma segura en TypeScript:

- `isNode(nodo)`: Verifica que el valor sea un nodo DOM válido (`nodeType` entre `1` y `11`).
- `isElement(nodo)`: Verifica `nodeType === 1`.
- `isAttribute(nodo)`: Verifica `nodeType === 2`.
- `isText(nodo)`: Verifica `nodeType === 3`.
- `isCDataSection(nodo)`: Verifica `nodeType === 4`.
- `isDocument(nodo)`: Verifica `nodeType === 9`.

::tip
`@nodecfdi/cfdi-core` también re-exporta las clases y constantes principales de `@xmldom/xmldom` (`DOMParser`, `XMLSerializer`, `DOMImplementation`, `Document`, `Element`, `Node`, `Attr`, `Text`, `CDATASection`, `MIME_TYPE`, `NAMESPACE`, `onErrorStopParsing`) y `Decimal` de `decimal.js`.
::
