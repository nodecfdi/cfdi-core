La clase `SchemaLocations` administra colecciones de pares `(namespace, location)` correspondientes al atributo XML `xsi:schemaLocation`.

## Creación e importación desde texto

Puedes construir una instancia desde un objeto o parsear directamente el valor del atributo `xsi:schemaLocation`:

```ts [schema-locations.ts]
import { SchemaLocations } from '@nodecfdi/cfdi-core';

// Desde objeto
const locations = new SchemaLocations({
  'http://www.sat.gob.mx/cfd/4':
    'http://www.sat.gob.mx/sitio_internet/cfd/4/cfdv40.xsd',
});

// Agregar otro esquema (por ejemplo TFD)
locations.append(
  'http://www.sat.gob.mx/TimbreFiscalDigital',
  'http://www.sat.gob.mx/sitio_internet/cfd/TimbreFiscalDigital/TimbreFiscalDigitalv11.xsd',
);

console.log(locations.asString());
```

### Métodos estáticos de parseo

- `SchemaLocations.fromString(value, includeLastUnpairedItem = false)`: Divide la cadena por espacios en pares `namespace location`. Si `includeLastUnpairedItem` es `true`, conserva un último namespace sin ubicación con valor `''`.
- `SchemaLocations.fromStringStrictXsd(value)`: Considera como ubicación únicamente los componentes que terminan en `.xsd`; cualquier otro elemento se registra como namespace con ubicación vacía `''`.

```ts [parseo-xsd.ts]
import { SchemaLocations } from '@nodecfdi/cfdi-core';

const raw
  = 'http://www.sat.gob.mx/cfd/4 http://www.sat.gob.mx/sitio_internet/cfd/4/cfdv40.xsd http://ejemplo.com/sin-xsd';

const strict = SchemaLocations.fromStringStrictXsd(raw);
console.log(strict.hasAnyNamespaceWithoutLocation()); // true
console.log(strict.getNamespacesWithoutLocation()); // ['http://ejemplo.com/sin-xsd']

// asString() omite entradas cuya ubicación está vacía
console.log(strict.asString());
```
