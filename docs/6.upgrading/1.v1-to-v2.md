La versión `2.0.0` de `@nodecfdi/cfdi-core` actualiza los requisitos de Node.js, introduce precisión decimal exacta mediante `decimal.js`, añade tipado genérico para atributos XML e incorpora módulos completos de descubrimiento de versiones, manejo de namespaces y utilidades fiscales.

## Cambios incompatibles (Breaking Changes)

### 1. Versión mínima de Node.js

El campo `engines.node` cambia de `>=18` a `^22.13.0 || ^24 || ^26`. La librería utiliza métodos modernos de ECMAScript (como `Array.prototype.toSorted`) y requiere Node.js 22.13+ o navegadores modernos compatibles con ES2022.

### 2. Precisión decimal en `formatNumber`, `roundNumber` y `toFloat`

Los cálculos numéricos dejan de depender de aritmética binaria de punto flotante (`Math.round`) y pasan a usar `decimal.js`:

- `formatNumber(value, decimals = 2)`: Ahora acepta `Decimal.Value` (`string | number | Decimal`) y el parámetro `decimals` es opcional (por defecto `2`).
- `roundNumber(num, precision)`: Ahora acepta `Decimal.Value` y redondea usando `new Decimal(num).toDecimalPlaces(precision).toNumber()`.
- `toFloat(value)`: Ahora usa `Number(value)` en lugar de `Number.parseFloat(value)`. Cadenas parcialmente numéricas como `'123abc'` devuelven `0` en lugar de `123`.

::code-group
```ts [v1.x]
import { formatNumber, roundNumber, toFloat } from '@nodecfdi/cfdi-core';

formatNumber(10.5, 2); // '10.50' (solo aceptaba number y precision obligatoria)
roundNumber(1.005, 2); // podía sufrir imprecisiones de punto flotante
toFloat('123abc'); // 123
```

```ts [v2.0.0]
import { formatNumber, roundNumber, toFloat } from '@nodecfdi/cfdi-core';

formatNumber('10.5'); // '10.50' (decimals = 2 por defecto, acepta string/number/Decimal)
roundNumber('1.005', 2); // 1.01 (precisión exacta con Decimal)
toFloat('123abc'); // 0
```
::

### 3. Salida del paquete y soporte para navegador (IIFE)

- La carpeta compilada interna cambia de `build/` a `dist/`. Si importas únicamente desde `@nodecfdi/cfdi-core` o `@nodecfdi/cfdi-core/types` no necesitas cambios en tus `import`.
- Se incluye un bundle autocontenido para navegador en `dist/index.iife.js` bajo la variable global `ncCfdiCore`. Consulta [Uso en navegador](/packages/cfdi-core/getting-started/browser-usage).

::warning
Si tu proyecto importaba rutas internas de la carpeta `build/` (no documentadas), debes migrar tus importaciones al punto de entrada público `@nodecfdi/cfdi-core` o `@nodecfdi/cfdi-core/types`.
::

## Nuevas funcionalidades en v2.0.0

Además de los cambios anteriores, la versión `2.0.0` incorpora herramientas que anteriormente requerían paquetes externos o lógica manual:

- **Tipado genérico en nodos y atributos**: `XmlNode<TAttributes>`, `XmlAttributes<TAttributes>` y `XmlNodeInterface<TAttributes>`, junto con los tipos `AttributeName` y `AttributesRecord` en `@nodecfdi/cfdi-core/types`. Revisa [Nodos y atributos](/packages/cfdi-core/xml-nodes/node-and-attributes).
- **Descubrimiento de versiones**: `CfdiVersion`, `TfdVersion`, `RetencionVersion` y la clase base `VersionDiscoverer`. Revisa [Descubridores incluidos](/packages/cfdi-core/version-discovery/discoverers).
- **Movers de espacios de nombres**: `SatNsDefinitionsMover` y `NodeNsDefinitionsMover`. Revisa [Espacios de nombres](/packages/cfdi-core/xml-nodes/namespace-definitions-mover).
- **Utilidades fiscales y de formato**:
  - `SchemaLocations` para manipular `xsi:schemaLocation`.
  - `CurrencyDecimals` para validar y redondear importes por moneda.
  - `RegimenCapitalRemover` para limpiar razones sociales según los requisitos de CFDI 4.0.
  - `formatDatetime` para fechas ISO en formato SAT y re-exportación de `Decimal`.

## Lista rápida de verificación

1. Actualiza tu entorno a **Node.js 22.13+** (o 24 / 26).
2. Instala la nueva versión (`npm install @nodecfdi/cfdi-core@^2.0.0`).
3. Revisa cualquier uso de `toFloat()` donde se esperara parseo parcial de cadenas con sufijos no numéricos.
4. Ejecuta tu suite de pruebas y `tsc --noEmit` para aprovechar el nuevo tipado genérico.
