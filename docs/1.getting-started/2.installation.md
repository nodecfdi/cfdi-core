Instala `@nodecfdi/cfdi-core` usando tu gestor de paquetes preferido. El paquete incluye sus dependencias principales (`@xmldom/xmldom` y `decimal.js`) y definiciones de tipos TypeScript.

::code-group
```bash [npm]
npm install @nodecfdi/cfdi-core
```

```bash [pnpm]
pnpm add @nodecfdi/cfdi-core
```

```bash [yarn]
yarn add @nodecfdi/cfdi-core
```

```bash [bun]
bun add @nodecfdi/cfdi-core
```
::

## Importación y tipos

El paquete expone dos puntos de entrada definidos en `package.json`:

- `@nodecfdi/cfdi-core`: Clases, funciones y re-exportaciones de `@xmldom/xmldom` y `Decimal`.
- `@nodecfdi/cfdi-core/types`: Tipos e interfaces de TypeScript (`XmlNodeInterface`, `ContainerWithAttributeInterface`, `AttributeName`, `AttributesRecord`, `NamespaceFilter`).

```ts [index.ts]
import type { XmlNodeInterface } from '@nodecfdi/cfdi-core/types';
import { CfdiVersion, nodeToXmlString, XmlNode } from '@nodecfdi/cfdi-core';
```

## Verificación rápida

Crea un archivo de prueba para construir un nodo CFDI, serializarlo a XML y validar la versión detectada:

```ts [verify.ts]
import {
  CfdiVersion,
  nodeFromXmlString,
  nodeToXmlString,
  XmlNode,
} from '@nodecfdi/cfdi-core';

const comprobante = new XmlNode('cfdi:Comprobante', {
  Version: '4.0',
  Serie: 'F',
  Folio: '1234',
});

const xml = nodeToXmlString(comprobante, true);
const parsed = nodeFromXmlString(xml);
const version = new CfdiVersion().getFromNode(parsed);

console.log({ xml, version });
```
