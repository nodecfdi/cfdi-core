`@nodecfdi/cfdi-core` es la librería base del ecosistema NodeCfdi para trabajar con Comprobantes Fiscales Digitales por Internet (CFDI) en JavaScript y TypeScript. Está inspirada en la arquitectura modular de `eclipxe13/CfdiUtils` para PHP.

## Características principales

- **Árbol de nodos XML independiente del DOM**: Crea, inspecciona, ordena y busca nodos mediante `XmlNode`, `XmlNodes` y `XmlAttributes`, con conversión bidireccional hacia y desde `@xmldom/xmldom`.
- **Descubrimiento de versiones**: Detecta automáticamente la versión de documentos CFDI (`3.2`, `3.3`, `4.0`), Timbre Fiscal Digital (`1.0`, `1.1`) y Retenciones (`1.0`, `2.0`), o crea descubridores propios extendiendo `VersionDiscoverer`.
- **Normalización de espacios de nombres**: Reubica declaraciones `xmlns:*` y `xsi:schemaLocation` al nodo raíz con `SatNsDefinitionsMover` y `NodeNsDefinitionsMover`.
- **Utilidades fiscales y numéricas**: Manejo de `xsi:schemaLocation` (`SchemaLocations`), precisión por moneda (`CurrencyDecimals`), limpieza de régimen societario (`RegimenCapitalRemover`) y helpers de formato (`formatNumber`, `formatDatetime`, `roundNumber`, `toFloat`).
- **Compatible con Node.js y navegador**: Disponible en ESM nativo con tipado TypeScript completo y como bundle IIFE (`ncCfdiCore`) listo para usarse directamente en navegadores.

## Requisitos

| Entorno | Requisito mínimo |
| --- | --- |
| Node.js | `^22.13.0 \|\| ^24 \|\| ^26` |
| Navegador | Navegadores modernos compatibles con ES2022 (sin IE 11) |
| Módulos | ESM (`"type": "module"`) o bundle IIFE en navegador |
