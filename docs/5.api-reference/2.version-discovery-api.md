Referencia de las clases del módulo de descubrimiento de versiones en `@nodecfdi/cfdi-core`.

## `VersionDiscoverer` (abstracta)

- `abstract rules(): Record<string, string>`
- `discover(container: ContainerWithAttributeInterface): string`
- `getFromDOMElement(element: Element): string`
- `getFromDOMDocument(document: Document): string`
- `getFromNode(node: XmlNodeInterface): string`
- `getFromXmlString(contents: string): string`

## Implementaciones incluidas

| Clase | Reglas (`rules()`) |
| --- | --- |
| `CfdiVersion` | `{ '4.0': 'Version', '3.3': 'Version', '3.2': 'version' }` |
| `TfdVersion` | `{ '1.1': 'Version', '1.0': 'version' }` |
| `RetencionVersion` | `{ '2.0': 'Version', '1.0': 'Version' }` |

## Contenedores

Implementan `ContainerWithAttributeInterface`:

- `DomElementContainer`: `constructor(element: Element)`, `getAttributeValue(attribute: string): string`
- `NodeContainer`: `constructor(node: XmlNodeInterface)`, `getAttributeValue(attribute: string): string`
